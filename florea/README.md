# Florea (Flutter)

Balance Your Mind, Study & Life.

## Prasyarat
- Flutter SDK >= 3.4, Android Studio, Git
- Akun Supabase (URL + anon key di `.env`)

## Jalan cepat
```bash
cd florea
cp .env.example .env
flutter pub get
flutter run --dart-define=SUPABASE_URL=... --dart-define=SUPABASE_ANON_KEY=...
```

Lihat `../FLOREA_TECH_STACK.md`, `../DATABASE_ERD.md`, `../DATABASE_SCHEMA.md`.
